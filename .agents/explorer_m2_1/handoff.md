## 2. Logic Chain
1. **Observation**: `MainActivity.kt` lines 58–69 instantiates `Retrofit` inside `RpgViewModel` and `NavigationKeys.kt` only defines `Main`.
   **Inference**: The current Android app is a temporary single-screen monolithic testbed requiring modularization before implementing Milestone 2 features.
2. **Observation**: `app/build.gradle.kts` lacks `firebase-auth-ktx`, `androidx.credentials`, `googleid`, and `logging-interceptor`.
   **Inference**: For Credential Manager API (`androidx.credentials`) and Firebase Auth token retrieval to function in Kotlin/Compose, these dependencies must be added to `libs.versions.toml` and `app/build.gradle.kts`.
3. **Observation**: Python middleware enforces HTTP Bearer headers (`Authorization: Bearer <token>`) for protected routes, while current Retrofit calls in `MainActivity.kt` send unauthenticated POST requests.
   **Inference**: Creating an `AuthInterceptor` implementing `okhttp3.Interceptor` to inject `authRepository.getValidBearerToken()` dynamically satisfies the security contract.
4. **Observation**: `Navigation.kt` currently uses Navigation 3 (`NavDisplay`, `rememberNavBackStack`).
   **Inference**: Refactoring the UI layout to wrap `NavDisplay` inside `ModalNavigationDrawer` and `Scaffold` with `DrawerNavigationItem`s ("Minhas Salas", "Meus Personagens", "Lores e Campanhas", "Perfil") cleanly extends the existing Navigation 3 stack.

## 3. Caveats
* **Google Web Client ID**: The Google ID token request requires `R.string.default_web_client_id`, which is automatically generated by the Google Services Gradle plugin from `google-services.json`. The actual string ID value will be validated upon runtime execution on a physical device.
